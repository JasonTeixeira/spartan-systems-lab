GPU Silicon & Roofline Physics (Why NVIDIA Dominates)

Prefill = Compute-Bound (Tensor Core BF16/FP8 FLOPs). Decode = HBM Bandwidth-Bound (H100 `3.35 TB/s` vs CPU `~100 GB/s`). Battle-Scarred Reflexes: Constraint-First Coding & 10 "30-Year Veteran" Laws

The hard-won production and interview reflexes textbooks never teach — internalize these so you sound war-tested in every room.

Unseen Hard Coding + Production Survival
Constraint-First Coding Reflex (Crack Unseen Hard LeetCode Cold) N ≤ 20: Backtracking / Bitmask DP O(2^N)  |  N ≤ 500: O(N^3)  |  N ≤ 5,000: O(N^2) 2D DP  |  N ≤ 10^5: Must be O(N) or O(N log N) (Hash, Two Pointers, Sliding Window, Monotonic Stack, Heap, Binary Search on Answer)  |  N ≥ 10^9: O(log N) or O(1). Always state your loop invariant out loud before coding.
Battle Scar #1

Hierarchical Timeouts (Inner < Outer)

Nginx 5s > FastAPI 4s > Postgres 3s. Reverse it and retries pile onto still-running dead DB queries.

Battle Scar #2

Decouple Breaking DB Migrations

v1 and v2 pods run together during rolling deploys. Always Expand → Deploy v2 → Contract.

Battle Scar #3

Throttle Mass Deletes & Backfills

Never delete 50M rows in 1 tx. Loop 5k–10k rows/tx with 50ms sleep to avoid lock & WAL lag storms.

Battle Scar #4

Queues Absorb Spikes, Not Overload

If write rate > drain rate permanently, Kafka just delays disk-full crash. Scale, batch, or shed load (`429`).

Battle Scar #5

Averages Always Lie — Check p99 & Skew

Avg 40ms hides p99 = 12s for your biggest paying enterprise tenant with 100x more rows.

Battle Scar #6

Idempotency + Forward State Machines

Beat "exactly-once" myths with At-Least-Once + `ON CONFLICT` + forward-only states (`PENDING → PAID`).

Battle Scar #7

Kill Switch & Fallback Before Launch

Every expensive LLM/RecSys call needs a feature flag + cached fallback so checkout survives vendor outages.

Battle Scar #8

Read Literal Source of Truth First

Check `EXPLAIN`, `pg_stat_activity`, `ss -tnp`, `curl -v`, `git log -n 5`, and stack line 1 before guessing.

Battle Scar #9

3-Second Production Safety Reflex

Verify context/env → run dry-run / `SELECT COUNT(*)` / `plan` → know exact rollback before hitting Enter.
